Why we built this

Most complaints about garbage go nowhere.

A phone call gets lost, a letter sits in a file, and nobody tells you what happened. SaafShehar puts every complaint on record, with a deadline and a person responsible.

The usual way

  • {% icon "x" 18 %} You don't know who to call, or the line is busy
  • {% icon "x" 18 %} No reference number, so you can't follow up
  • {% icon "x" 18 %} No deadline. It gets done "soon"
  • {% icon "x" 18 %} "Done" with no proof that anyone came
  • {% icon "x" 18 %} The city never sees which areas suffer most

With SaafShehar

  • {% icon "check" 18 %} One photo and a tap. It goes to your ward's team
  • {% icon "check" 18 %} A complaint number like SS-2026-0042 to track anytime
  • {% icon "check" 18 %} Every type of problem has a fixed clean-up deadline

{# ---------------------------------------------------------------- faq #}
Questions

Things people usually ask.

Does it cost anything? {% icon "plus" 18 %}

No. Reporting, tracking and rating are free for every citizen.

Which photos are accepted? {% icon "plus" 18 %}

Clear JPG, PNG or WEBP photos up to 5 MB, at least 200 pixels on each side. We check the file really is an image.

How many complaints can I file? {% icon "plus" 18 %}

Up to 5 in 24 hours. If you already reported the same kind of problem in the same ward today, we'll point you to that complaint so the team doesn't get duplicates.

What if it isn't really clean? {% icon "plus" 18 %}

Open the complaint and tap "Reopen" within 7 days. Tell us what's still wrong and the team is alerted again.

Can I check a complaint without signing in? {% icon "plus" 18 %}

Yes. Enter the complaint number on the Track page, for example SS-2026-0001.

Who can see my name and phone number? {% icon "plus" 18 %}

Only the municipal team. Other citizens only see your first name on complaints in the community list.
